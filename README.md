# 国科大模拟选课系统

一个面向中国科学院大学研究生选课规划的单文件离线网页。所有页面逻辑、默认课程数据和 XLSX 导入器均内嵌在 `index.html` 中，不需要安装依赖或运行后端。

> 本工具只用于个人排课与学分规划，不会连接学校系统或提交真实选课结果。课程信息、培养方案和选课资格请以国科大官方系统及通知为准。

## 主要功能

- 秋季、春季、夏季三套独立的主选、备选和周课表；学分跨学期汇总。
- 按名称、编码、院系、属性、层次、校区、星期和节次筛选课程。
- 主选课程自动检测时间冲突；备选允许冲突，并显示与哪些主选课程冲突。
- 设置学生类别、专业和学分门槛，检查本专业“2 门核心课＋2 门专业课”；专业列表从三学期真实课表自动生成。
- 汇总课程总学分、专业学位课、公共选修课、专业选修课及秋春学期学分下限。
- 主选、备选、当前学期、查看周次和个人要求自动保存在浏览器中。
- 将当前学期主选课程导出为 iCalendar（ICS）日历文件。
- 直接在页面中导入同格式 `.xlsx` 课表并替换当前学期目录，无需 Python 或第三方 JS 文件。

## 默认课表数据

| 学期 | 数据年份 | 课程数 |
| --- | --- | ---: |
| 秋季 | 2026–2027 学年 | 2079 |
| 春季 | 2025–2026 学年历史数据 | 1887 |
| 夏季 | 2025–2026 学年历史数据 | 120 |

春季和夏季默认数据用于提前规划，正式开课情况请以当学期发布的课程目录为准。

## 使用方式

下载并双击打开：

```text
index.html
```

页面运行只依赖这一个 HTML。推荐使用新版 Chrome、Edge 或 Firefox，以获得完整的 XLSX 解压和本地持久化能力。

### 导入新课表

1. 切换到要替换的秋季、春季或夏季。
2. 点击“导入 XLSX 到当前学期”。
3. 选择国科大课表格式的 `.xlsx` 文件。
4. 导入目录保存在浏览器 IndexedDB 中，刷新页面后仍然有效。
5. 如需撤销，点击“恢复当前学期默认数据”。

导入器能够绕过部分课表文件中错误的 `A1` 工作表维度，支持内联字符串、共享字符串、多行课程时段以及 `周一(7-8,10-11)` 形式的非连续节次。

## 数据与隐私

- 所有选课方案和导入数据只保存在当前浏览器本地。
- 页面不会上传课表、专业设置或选课方案。
- 清除浏览器站点数据、使用无痕模式或更换浏览器后，本地记录可能消失。
